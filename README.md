# Donut Portfolio

A playful, single-page portfolio that opens with a 3D donut you can click to split open and spill cream.

Built with **React 19**, **Three.js** (WebGL donut intro) and **Vite**.

## Features

- 3D donut intro — click it, it splits open, grows, and spills cream down the screen
- Donut-themed About, Projects (timeline) and Contact sections
- Sprinkles, drips, half-donuts and a donut cursor — the whole page is on theme

## Run it

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
